# Projeto Front-end

Projeto desenvolvido no início da graduação com foco em estruturação de páginas web e fundamentos de HTML e CSS.

## 🛠️ Tecnologias utilizadas
- HTML
- CSS

## 🎯 Objetivo do projeto
Compreender a estrutura básica de uma aplicação web, organização de conteúdo e boas práticas iniciais de front-end.

## 📚 Observação
Projeto acadêmico voltado ao aprendizado.
